# Fonts

Served with the application, so the browser makes no request to an external service (PRI02, C03). Each font is under the SIL Open Font License 1.1; the licence texts are next to the files.

|---|---|---|---|
| EB Garamond (variable weight, normal and italic) | `eb-garamond-latin-wght-*.woff2` | Copyright 2017 The EB Garamond Project Authors (https://github.com/octaviopardo/EBGaramond12) | [OFL 1.1](OFL-EB-Garamond.txt) |
| IBM Plex Sans (400, 500, 600) and IBM Plex Mono (400) | `ibm-plex-*.woff2` | Copyright © 2017 IBM Corp. (https://github.com/IBM/plex) | [OFL 1.1](OFL-IBM-Plex.txt) |

The `woff2` files are the Latin subsets packaged by Fontsource (`@fontsource-variable/eb-garamond@5.2.5`, `@fontsource/ibm-plex-sans@5.2.5`, `@fontsource/ibm-plex-mono@5.2.5`), downloaded once on 2026-11-11. They aren't npm dependencies of the project.
