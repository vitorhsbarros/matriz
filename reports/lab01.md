## Exercício 1

Prompt Simples: "Quero criar uma aplicação de gestão de projetos e tarefas chamada Matriz. Ajuda-me a desenvolver a aplicação."

Funcionalidades sugeridas:

#### Plataforma:

Que tipo de aplicação queres construir?

- Web (frontend + backend)
- Só backend/ API REST
- Aplicação CLI
- Other

#### Stack:

Que Stack tecnológica preferes?

- Java + Spring Boot (recomendado)
- Node.js + Typescript
- Python
- Other

#### Âmbito (resposta múltipla):

Que funcionalidades queres na primeira versão?

- Projectos e tarefas (CRUD)
- Estados / quadro Kanban
- Utilizadores e Autenticação
- Matriz de Eisenhower
- Other

#### Contexto

Isto é para um trabalho da faculdade com requisitos definidos?

- Sim, tenho um enunciado
- Não, é um projecto pessoal
- Other

### Resposta

A IA sugeriu algumas funcionalidades mas deixou sempre a decisão final para o utilizador. Nenhuma decisão foi assumida pela IA neste caso. Existiu proposta de tecnologias, mas não propôs/sugeriu arquiteturas.
