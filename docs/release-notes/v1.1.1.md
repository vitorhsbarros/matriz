# Matriz 1.1.1 — Release notes

**Version:** `1.1.1`, Git tag `v1.1.1` on `main`, released on 2026-11-16.
**Image:** `ghcr.io/vitorhsbarros/matriz:1.1.1` (also `latest`), for `linux/amd64`, with a signed provenance attestation.
**Previous release:** [1.1.0](v1.1.0.md).

## Version number

A **patch** over `1.1.0` ([Semantic Versioning](https://semver.org/spec/v2.0.0.html)): it fixes and tidies, and adds nothing that changes how Matriz is used.
- The API (`openapi.yaml`), the database (no migration), the settings and the features are the same.
- The provenance attestation and the deployment comparison are about how the image is published and documented, not about the application.

## What changed

- **Readiness answers sooner while the database is down.** `/actuator/health/readiness` answered `DOWN` after 30 s, the default time-out for a database connection. With a 5 s time-out it now answers in about 5 s. A request that waits for a connection also gives up after 5 s instead of 30 s; with about 50 users and a pool of 10 connections, that wait shouldn't be reached.
- **No unused persistence library.** Data access was always Spring's `JdbcClient`, with the schema owned by the Flyway migrations. Spring Data JPA and Hibernate were in the build but never used, so they were removed: the JAR went from 60.6 MB to 31.8 MB, the image from 165 MB to 139 MB (compressed), and the application starts in about 2 s instead of 4 s.
- **The version is the release's.** `pom.xml` says `1.1.1`, so the application logs `Starting MatrizApplication v1.1.1` and `service.version` is `1.1.1`. The JAR is now `target/matriz.jar`, whatever the version.
- **Provenance attestation.** CI signs a statement of which commit and workflow run built each published image, and stores it on GitHub and in the registry. Check it with:

  ```bash
  gh attestation verify oci://ghcr.io/vitorhsbarros/matriz:1.1.1 -R vitorhsbarros/matriz
  ```
- **Deployment options.** [docs/deployment-options.md](../deployment-options.md) compares the deployment platforms for the pending decision PD13.

Every change is listed in [CHANGELOG.md](../../CHANGELOG.md).

## Upgrading from 1.1.0

- **Running the JAR:** the file is now `target/matriz.jar` (was `target/matriz-0.1.0-SNAPSHOT.jar`).
- **The image:** `docker pull ghcr.io/vitorhsbarros/matriz:1.1.1`. No setting changes and no data migration.

## Known issues and open points

- **Not deployed.** The deployment platform is still to be decided (PD13): see [deployment-options.md](../deployment-options.md).
- **amd64 only.** On an arm64 machine the image runs under emulation.
- **The Java runtime isn't scanned.** The image scan sees the Ubuntu packages, and the dependency scan the Java libraries, but neither sees the Temurin runtime.
