Viewed as Ana Silva, a demo account (US19): manager of Website and Intranet, member of App. Click a project to open its board, and a task title to open its details; use the links at the top to go back.

Dark labels (US04, US05 …) show which user story each element comes from. They are annotations, not part of the interface.

Deleting asks for confirmation on the page first (NFR05). Only the manager can delete a project; any member can delete a task; only the author can edit or delete a comment.
